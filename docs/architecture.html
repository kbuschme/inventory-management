Factory Inventory Management System

A demo full-stack dashboard: Vue 3 single-page app, FastAPI backend, and in-memory data loaded from JSON files. There is no database.

System architecture

Browser - Vue 3 SPA - http://localhost:3000
App.vue (nav shell) FilterBar Vue Router 7 view pages 9 components (modals, menus) Composables: useFilters, useAuth, useI18n
HTTP / JSON via axios (client/src/api.js) - query-parameter filters
API - FastAPI + Uvicorn - http://localhost:8001
server/main.py CORS middleware (all origins) apply_filters / filter_by_month Pydantic response models
Python imports of module-level lists
Data - in memory, read-only after startup
server/mock_data.py inventory.json orders.json demand_forecasts.json backlog_items.json purchase_orders.json spending.json transactions.json

Data flow

  1. User changes a filterPeriod, Warehouse, Category or Order Status in FilterBar.
  2. Shared state updatesuseFilters holds the four selections as module-level refs, so every view sees the same values.
  3. View watcher firesThe view (for example Dashboard) watches the refs and calls getCurrentFilters().
  4. API client builds the requestapi.js adds only non-"all" filters as query parameters.
  1. FastAPI filters in memoryapply_filters matches warehouse, category and status; filter_by_month handles months and quarters (Q1-Q4 2025) on order_date.
  2. Pydantic validates the responseresponse_model shapes the JSON returned to the browser.
  3. Raw data lands in refsViews store results in refs such as allOrders and inventoryItems.
  4. Computed properties derive the UITotals, chart series and tables are computed from the refs, then rendered.

Things to know

Missing backend routes. api.js calls /tasks (list, create, delete, toggle) and /purchase-orders (create, get by backlog item), but main.py defines no such routes. Those calls would return 404. The PurchaseOrder models exist, and purchase orders are only read to compute has_purchase_order.
Data is static. JSON files are loaded once at startup, so nothing persists and restarting the server resets everything. purchase_orders.json is effectively empty.
Open CORS and mock auth. CORS allows all origins, and useAuth sets isAuthenticated to true by default. Both are fine for a demo, not for production.
Hard-coded API URL. API_BASE_URL is http://localhost:8001/api in api.js, with no environment-based configuration.
